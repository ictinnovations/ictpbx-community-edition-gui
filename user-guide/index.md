# ICTPBX User Guide

**ICTPBX** is a hosted PBX and fax management platform built on FusionPBX / FreeSWITCH. It comes in two editions:

| | Service Provider Edition (EE) | Community Edition (CE) |
|---|---|---|
| Multi-tenant | ✅ | ❌ (single tenant) |
| Billing, packages & quotas | ✅ | ❌ |
| Branding | ✅ | ❌ |
| SMS messaging (SignalWire) | ✅ | ❌ |
| AI Voice Agent (optional add-on) | ✅ | ❌ |
| PBX features | ✅ Full | ✅ Full |
| Fax features | ✅ Full | ✅ Full |

> Features marked **(Service Provider Edition)** are exclusive to the multi-tenant Service Provider Edition.
